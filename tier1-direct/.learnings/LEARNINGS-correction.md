```markdown
**代价**：（回滚 / 重做 / 用户信任损耗，越具体越好）

**根因**：（AI 为什么会犯这个错——基于什么错误判断 / 跳过了什么流程）

**对策**：（写到 AGENTS.md 或 RULES.md 的硬条款是什么）

**晋升状态**：未晋升 / 等待累积 / 已晋升至 <target> on YYYY-MM-DD
```
